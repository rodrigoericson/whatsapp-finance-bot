# Checklist de Release

## Antes do release

- [ ] Branch limpa
- [ ] Build OK
- [ ] Testes OK
- [ ] Frontend build OK, se aplicável
- [ ] Code review feito
- [ ] Security review feito, se aplicável
- [ ] Docs atualizadas
- [ ] Migrations validadas
- [ ] Config/deploy revisados
- [ ] Sem secrets no diff

## Versionamento

- [ ] Definir versão semântica
- [ ] Atualizar changelog
- [ ] Criar tag

## Pós-release

- [ ] Validar ambiente
- [ ] Monitorar logs
- [ ] Registrar incidentes/lições aprendidas
- [ ] Atualizar memória do projeto
